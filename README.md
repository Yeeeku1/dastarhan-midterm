# Dastarhan Restaurant Website

A responsive six-page website concept for a modern Kazakh restaurant, created for the SE-2527 Midterm Project by Yerasyl, Dosymzhan, and Dastan.

## Pages

- `index.html` — Home
- `about.html` — Our Story
- `menu.html` — Menu with a semantic HTML table
- `gallery.html` — Photo gallery
- `reservation.html` — Reservation request form
- `contact.html` — Contact and visit information

## Run the website

Open `index.html` in a browser. The project uses a shared local `styles.css` file and Bootstrap 5.3 via CDN. An internet connection is needed for Bootstrap, Google Fonts, and the external Unsplash photos.

The reservation form is a front-end demonstration that opens the visitor's email app. It does not store or send bookings to a restaurant server.

## Midterm features

- Semantic HTML5 page structure, consistent navigation, and footer
- Bootstrap stylesheet and utility classes
- CSS Flexbox, Grid, and relative, absolute, fixed, and sticky positioning
- Two custom responsive breakpoints for tablet and mobile, plus a small-screen refinement
- Accessible labels and alternative text for images
- Multi-page navigation, menu table, and reservation form
